# Daily Ultimate Tic-Tac-Toe

## Mission

Build a premium-feeling Daily Ultimate Tic-Tac-Toe game for the web.

The experience should feel closer to Wordle, Chess.com, and Monument Valley than a classroom project.

The focus is:

- beautiful UI
- smooth animations
- excellent UX
- strategic gameplay
- fast loading
- mobile-first

Do not add unnecessary features.

Quality over quantity.

---

## Rules

- Build one feature at a time.
- Explain the implementation plan before coding.
- Reuse components.
- Keep game logic separated from UI.
- Use TypeScript throughout.
- Use Motion for React for animations.
- Keep the code production quality.
- Stop after each completed feature and wait for approval.
